# 🎨 clip-lora-studio

Application Gradio pour l'analyse et la démonstration de modèles CLIP + LoRA.

## Structure

- `app.py` — Application Gradio principale
- `checkpoints/` — Modèles entraînés
- `assets/` — Figures, données et images d'exemple
- `modules/` — Code Python
- `utils/` — Utilitaires et constantes

## Installation

```bash
pip install -r requirements.txt
python app.py
```
